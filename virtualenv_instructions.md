# Інструкція зі створення віртуального середовища та встановлення залежностей

## 1. Створення віртуального середовища

Відкрийте термінал у папці проекту (`hw1`) і виконайте команду:

```
python -m venv venv
```

Це створить папку `venv` з ізольованим Python-середовищем.

---

## 2. Активація віртуального середовища

### Для Windows PowerShell:

```
.\venv\Scripts\Activate.ps1
```

### Для Windows CMD:

```
.\venv\Scripts\activate.bat
```

---

## 3. Встановлення залежностей

У цьому проекті потрібна лише бібліотека `numpy`. Встановіть її командою:

```
pip install numpy
```

---

## 4. Збереження залежностей у файл requirements.txt

Після встановлення залежностей виконайте:

```
pip freeze > requirements.txt
```

---

## 5. Встановлення залежностей з requirements.txt (для інших користувачів)

```
pip install -r requirements.txt
```

---

## 6. Деактивація віртуального середовища

```
deactivate
```
